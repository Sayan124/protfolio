# SAYAN.OS

A responsive minimalist portfolio for Sayan Nandi, built with React, Vite, Three.js, React Three Fiber, and Drei. It pairs a pointer-responsive neural core with a restrained glass-inspired interface and clearly marked project and contact placeholders.

## Run locally

Install a current Node.js LTS release, then from this folder run:

```bash
npm install
npm run dev
```

Open the local address printed by Vite. To create a production bundle, run `npm run build`; `npm run preview` serves that bundle locally.

## Project map

- `src/App.jsx` — page sections, navigation, and the core status readout.
- `src/components/NeuralCore.jsx` — procedural, mouse-responsive neural network scene.
- `src/styles.css` — visual system and responsive layout.

The project card and contact channel are deliberately marked as placeholders until real work and contact details are ready. The profile currently includes only the interests and degree information provided.
